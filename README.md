# korean-rnd-mcp

한국 정부의 R&D정책, 부처별 법정계획 KISTEP 등에서 발간되는 과학기술 관련 보고서(기술수준 비교 등)에서
프롬프트에서 요구하는 답변 생성에 도움이 될만한 원문을 찾아 AI에게 전달하는 MCP 서버입니다.

> 자매 서비스 [korean-rnd-regs-mcp](https://github.com/smilemin07/korean-rnd-regs-mcp)는 국가연구개발 **법령·규정 조문**(연구비 사용기준, 반납 절차 등) 검토용이고, 본 서비스는 **정책·계획·보고서 본문**의 근거 검색용입니다. 규정 조문이 필요한 질문은 자매 서비스를 이용하십시오.

## 빠른 시작

### Claude.ai (웹) / Claude Desktop — 개인 계정

1. claude.ai 로그인 → 왼쪽 사이드바 **Customize** → **Connectors**
2. **+** → **Add custom connector**
3. Name: `korean-rnd-mcp`, URL: `https://korean-rnd-mcp.rndmanagers.org/mcp` → **Add**
4. 새 대화를 열고 **+** → **Connectors**에서 `korean-rnd-mcp`가 켜져 있는지 확인
  
※ AI가 korean-rnd-mcp에서 제공하는 도구의 사용 승인을 요청하는 경우, 승인 필요

### Claude Code

```
claude mcp add --transport http korean-rnd-mcp https://korean-rnd-mcp.rndmanagers.org/mcp
```

새 대화에서 아래처럼 물어보십시오. 문서명과 쪽수가 붙은 구절이 돌아오면 정상입니다.

> korean-rnd-mcp로 제7차 건설기술진흥 기본계획의 추진 전략을 찾아줘

※ 참조를 원하는 문서명을 명시하면 정확도가 상승
※ "현행 계획 중에서"라고 쓰면 현행으로 분류해 둔 계획 문서만 검색

## 결과 읽는 법

사용자는 평소처럼 질문만 하면 됩니다. AI가 다음 기능을 자동으로 호출합니다(명령어를 직접 입력할 필요 없음).

- **근거 검색**: 질문과 관련된 구절 후보를 문서명·PDF 쪽수(인쇄면 번호 병기)·원문 URL과 함께 찾아옵니다. 원문 URL은 등재된 모든 문서(2026-11-10 기준 157건)에 붙습니다.
- **구절 전문 조회**: 발췌가 잘렸을 때 해당 구절(저장 단위) 전체를 가져옵니다. 문서 전체를 제공하는 기능은 아닙니다.
- **문서 정보 조회**: 발행 기관, 같은 문서의 다른 판본(보도자료·요약본 등), 현행/구판 상태, 페이지 품질을 확인합니다.

알아 두실 점:

1. **근거인지는 이용자가 확인해야 합니다.** 서버는 "관련 가능성이 높은 구절"을 찾아줄 뿐, 그 구절이 질문에 대한 답인지 판정하지 않습니다. AI의 요약과 제시된 원문 구절이 맞는지 직접 대조하시기 바랍니다.
2. **결과가 없다고 해서 그런 정책이 없는 것은 아닙니다.** 이 서비스는 등재된 문서 안에서만 검색합니다. 서버는 AI가 "코퍼스에 근거가 없다"거나 "다른 문서가 존재한다"고 단정하지 않도록 지시합니다.
3. **출처 표기는 AI가 작성합니다.** 서버는 사용한 문서의 URL을 답변 하단에 적도록 AI에 안내하고 도구 응답에 URL을 담아 보내지만, 최종 답변은 AI가 쓰므로 누락될 수 있습니다. 빠졌다면 "문서명·쪽수·원문 URL을 다시 표시해 줘"라고 요청하십시오. 
4. **"현행"은 코퍼스 생성 시점을 기준으로 분류됩니다.** 문서의 최신성은 발행 기관에서 확인하시기 바랍니다.

## 코퍼스(Library = 현 MCP가 가지고 있는 자료 창고)

공개 정부 문서 **157건, 13,042쪽** (2026-11-10 기준). 과학기술정보통신부·KISTEP·관계부처 합동·국토교통부 등의 국가연구개발 투자방향, 기본계획·종합계획, 심의안건, 조사·분석 보고서, 보도자료를 담고 있으며 계획 문서 79건에는 현행/구판 상태가 등재되어 있습니다. 전체 목록과 문서별 원문 링크는 [docs/CORPUS.md](docs/CORPUS.md)에 있습니다.

- **정적 코퍼스**: 운영자가 선별해 등재한 문서만 포함되며 새 발표 자료가 자동으로 추가되지 않습니다. 갱신은 비정기 수동이며 다음 갱신 시점을 보장하지 않습니다. 갱신 시 이 문서와 목록의 기준일을 바꿉니다.
- **제공 기준**: 공공기관이 공개한 정책·계획·보고서 원문을 대상으로 합니다.
- **출처 표시**: 검색 결과에는 발행 기관·문서명·쪽수·원문 URL이 함께 제공됩니다.

## 개인정보·국외 처리 고지

- 검색 질의는 임베딩 계산을 위해 미국 법인 Cloudflare, Inc.의 Workers AI로 암호화 전송되어 즉시 처리됩니다.
- 운영자 서버는 질의 원문을 저장하지 않습니다. Cloudflare는 [Workers AI 데이터 정책](https://developers.cloudflare.com/workers-ai/platform/data-usage/)에서 고객 콘텐츠를 AI 모델 학습에 쓰지 않는다고 밝히고 있습니다.
- 검색 질의에 개인정보·기밀을 넣지 마십시오.

## 이용 제한과 문제 해결

속도·동시 처리·일일 검색 한도가 있습니다.

- 검색 질의 1건은 500자 이내입니다(대화 전체가 아니라 AI가 서버에 보내는 검색 문장 기준). 긴 질문은 나누어 물으십시오.
- 요청이 몰리면 잠시 거부될 수 있습니다. 1~2분 후 다시 시도하십시오.
- 하루 의미 기반 검색 한도가 소진되면 그날은 검색이 명시적으로 중단되고(품질을 낮춘 결과로 대체하지 않음) 다음 날 0시(UTC, 한국시간 오전 9시)에 재개됩니다.
- 운영자가 점검·중단 중이면 연결이 계속 실패할 수 있습니다. 별도 상태 페이지는 없습니다.

오류 코드가 보일 때: `429` 속도 제한(잠시 후 재시도) · `503` 혼잡·점검·중단(즉시 재시도가 실패할 수 있음) · `413` 요청이 너무 큼.

## 이용상 주의 및 면책

본 서비스는 정책 문서의 근거 탐색을 돕기 위한 무료·무SLA 공개 알파 도구로, 현 상태 그대로 제공됩니다. 운영자는 검색 결과의 정확성·완전성·특정 목적 적합성과 계속 제공을 보증하지 않으며, 예고 없이 변경·중단·종료할 수 있습니다. 검색 결과는 공식 유권해석이나 행정·법적 판단의 최종 근거가 될 수 없으므로, 업무·의사결정에는 반드시 각 문서의 원문(답변 하단 URL)과 소관 기관의 공식 발표를 확인하십시오. 운영자의 고의 또는 중대한 과실 등 관계 법령상 배제할 수 없는 책임을 제외하고, 서비스 이용·중단으로 인한 손해에 대해 책임지지 않습니다.
