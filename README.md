# korean-rnd-mcp

한국 정부 R&D 정책문서·계획·보고서에서 **출처와 쪽수가 붙은 근거 구절**을 찾아 주는 원격 MCP 서버입니다.
Claude 같은 AI에 연결해 두면, 정책 질문에 답할 때 "어느 문서 몇 쪽에 그렇게 쓰여 있는지"를 함께 제시합니다.

- 주소: `https://korean-rnd-mcp.rndmanagers.org/mcp`
- 요금: **무료**. 인증·회원가입·API 키 없음
- 지위: **무료·무SLA 공개 알파** (보증 범위와 주의사항은 말미의 "이용상 주의 및 면책" 참조)

> 자매 서비스 [korean-rnd-regs-mcp](https://github.com/smilemin07/korean-rnd-regs-mcp)는 국가연구개발 **법령·규정 조문**(연구비 사용기준, 반납 절차 등) 검토용이고, 본 서비스는 **정책·계획·보고서 본문**의 근거 검색용입니다. 규정 조문이 필요한 질문은 자매 서비스를 이용하십시오.

## 빠른 시작

### Claude.ai (웹) / Claude Desktop — 개인 계정

1. claude.ai 로그인 → 왼쪽 사이드바 **Customize** → **Connectors**
2. **+** → **Add custom connector**
3. Name: `korean-rnd-mcp`, URL: `https://korean-rnd-mcp.rndmanagers.org/mcp` → **Add**
4. 새 대화를 열고 **+** → **Connectors**에서 `korean-rnd-mcp`가 켜져 있는지 확인

- Team·Enterprise 요금제는 조직 Owner가 **Organization settings → Connectors**에서 먼저 등록해야 합니다. 메뉴 이름과 무료 계정의 커스텀 커넥터 허용 개수는 Claude 업데이트·요금제에 따라 다를 수 있습니다.
- 도구 권한은 기본값(Needs approval)을 유지해도 됩니다. 질문마다 승인 창이 뜨는 것이 번거롭고 이 서버와 운영자를 신뢰하신다면 **Always allow**로 바꿀 수 있습니다.

### Claude Code

```
claude mcp add --transport http korean-rnd-mcp https://korean-rnd-mcp.rndmanagers.org/mcp
```

### 그 밖의 도구 (Cursor, Windsurf 등)

각 도구의 MCP 설정에서 위 주소를 원격 서버로 등록하면 됩니다(Streamable HTTP, 인증 없음). 2026-08-21 기준 실제 연결을 확인한 클라이언트는 Claude Code와 MCP 표준 클라이언트이며, Claude.ai 커넥터 절차는 자매 서비스에서 검증된 절차와 같습니다.

## 질문 예시 (2026-08-21 실제 검색으로 확인)

- "2027년도 국가연구개발 투자방향에서 중점 투자 분야로 제시된 것은?"
- "제6차 과학기술기본계획의 전략과 핵심 과제는?"
- "제4차 물류시설개발 종합계획의 계획 기간과 주요 과제는?"
- "현행 계획 중에서 재난안전 기술개발 추진 전략을 찾아줘"

질문 요령: 문서명을 함께 쓰면 정확도가 높아집니다. "현행 계획 중에서"라고 쓰면 운영자가 현행으로 분류해 둔 계획 문서만 검색합니다(구판 제외).

## 결과 읽는 법

사용자는 평소처럼 질문만 하면 됩니다. 연결된 AI가 뒤에서 다음 기능을 자동으로 호출합니다(명령어를 직접 입력할 필요 없음).

- **근거 검색**: 질문과 관련된 구절 후보를 문서명·PDF 쪽수(인쇄면 번호 병기)·원문 URL과 함께 찾아옵니다. 원문 URL은 등재된 모든 문서(2026-11-10 기준 157건)에 붙습니다.
- **구절 전문 조회**: 발췌가 잘렸을 때 해당 구절(저장 단위) 전체를 가져옵니다. 문서 전체를 제공하는 기능은 아닙니다.
- **문서 정보 조회**: 발행 기관, 같은 문서의 다른 판본(보도자료·요약본 등), 현행/구판 상태, 페이지 품질을 확인합니다.

반드시 알아 두실 점:

1. **근거인지는 이용자가 확인해야 합니다.** 서버는 "관련 가능성이 높은 구절"을 찾아줄 뿐, 그 구절이 질문에 대한 답인지 판정하지 않습니다. AI의 요약과 제시된 원문 구절이 맞는지 직접 대조하십시오.
2. **결과가 없다고 해서 그런 정책이 없는 것은 아닙니다.** 이 서비스는 등재된 문서 안에서만 검색합니다. 서버는 AI가 "코퍼스에 근거가 없다"거나 "다른 문서가 존재한다"고 단정하지 않도록 지시합니다.
3. **출처 표기는 AI가 작성합니다.** 서버는 사용한 문서의 URL을 답변 하단에 적도록 AI에 안내하고 도구 응답에 URL을 담아 보내지만, 최종 답변은 AI가 쓰므로 누락될 수 있습니다. 빠졌다면 "문서명·쪽수·원문 URL을 다시 표시해 줘"라고 요청하십시오. 2026-09 개정으로 도구 응답에 사용 문서 목록(`candidate_source_manifest`)과 답변 작성 요건(`answer_requirements`)이 추가되었습니다 — 효과는 실측 평가 중이며 "해결"을 보장하지 않습니다. 원문 URL이 등록되지 않은 문서는 "원문 URL 미확보"로 표기되도록 안내합니다.
4. **"현행"은 기준일 기준 운영자 분류입니다.** 2026-08-21 이후 새 계획이 발표되었을 수 있으니 최신성은 발행 기관에서 다시 확인하십시오.
5. 발표 슬라이드처럼 이미지로만 된 페이지는 색인되지 않았으며, 해당 문서가 질문과 관련될 때 AI에 누락 가능성이 함께 전달됩니다.

## 코퍼스

공개 정부 문서 **157건, 13,042쪽** (2026-11-10 기준). 과학기술정보통신부·KISTEP·관계부처 합동·국토교통부 등의 국가연구개발 투자방향, 기본계획·종합계획, 심의안건, 조사·분석 보고서, 보도자료를 담고 있으며 계획 문서 79건에는 현행/구판 상태가 등재되어 있습니다. 전체 목록과 문서별 원문 링크는 [docs/CORPUS.md](docs/CORPUS.md)에 있습니다.

- **정적 코퍼스**: 운영자가 선별해 등재한 문서만 포함되며 새 발표 자료가 자동으로 추가되지 않습니다. 갱신은 비정기 수동이며 다음 갱신 시점을 보장하지 않습니다. 갱신 시 이 문서와 목록의 기준일을 바꿉니다.
- **제공 기준**: 공공기관이 공개한 정책·계획·보고서 원문을 대상으로 합니다. 2026-08-21·2026-11-05 전수 확인 당시 공공누리 제2·4유형(상업적 이용 제한) 표시 문서는 없었고, 향후 발견되면 제외합니다. 공공누리 제1유형(출처표시) 표시 문서 9건은 출처표시 조건으로 포함했습니다. 민간·해외·개인 저작물은 제외했습니다.
- **출처 표시**: 검색 결과에는 발행 기관·문서명·쪽수·원문 URL이 함께 제공됩니다. 결과를 인용·재사용할 때는 이 정보를 유지해 각 문서의 이용조건(공공누리 유형 등)에 맞게 출처를 표시하십시오. AI가 만든 URL 목록만으로 모든 출처표시 조건이 충족된다고 보장하지 않습니다.

## 개인정보·국외 처리 고지

이 고지는 AI가 본 서버의 검색 기능에 전달한 **검색 질의**의 처리에 관한 것입니다. Claude 등 AI 서비스에 입력한 대화 전체의 처리는 해당 AI 사업자의 개인정보 처리방침을 따릅니다.

- **국외 처리**: 검색 질의는 의미 기반 검색(임베딩 계산)을 위해 미국 법인 **Cloudflare, Inc.**의 Workers AI 처리 인프라(글로벌 네트워크)로 암호화 통신을 통해 전송되어 즉시 처리됩니다. 질의가 어느 국가의 서버에서 처리되는지는 운영자가 지정하지 않습니다.
- **보관·학습**: 운영자의 서버는 질의 원문을 저장하지 않습니다. Workers AI에 별도 저장 서비스를 연결하지 않았으며, Cloudflare는 [Workers AI 데이터 정책](https://developers.cloudflare.com/workers-ai/platform/data-usage/)에서 고객 콘텐츠를 AI 모델 학습에 사용하지 않는다고 밝히고 있습니다.
- **운영자가 기록하는 것**: 요청 건수·처리 상태·응답 시간·질의 길이 구간(통계). 접속 IP는 속도 제한을 위해 메모리에서만 사용하며(마지막 요청 후 10분 이내 삭제) 로그에 남기지 않습니다. Cloudflare 네트워크의 연결 메타데이터 처리는 Cloudflare 정책을 따릅니다.
- **개인정보를 넣지 마십시오.** 무저장 정책과 별개로, 개인정보·기밀·대외비·미공개 과제 정보는 검색 질의에 포함하지 마십시오. 이용을 원하지 않으면 커넥터를 끄면 되며, 이 경우 본 서비스의 검색을 이용할 수 없습니다.

## 이용 제한과 문제 해결

무료 알파이므로 속도·동시 처리·일일 검색 한도가 있습니다.

- 검색 질의 1건은 500자 이내입니다(대화 전체가 아니라 AI가 서버에 보내는 검색 문장 기준). 긴 질문은 나누어 물으십시오.
- 요청이 몰리면 잠시 거부될 수 있습니다. 1~2분 후 다시 시도하십시오.
- 하루 의미 기반 검색 한도가 소진되면 그날은 검색이 명시적으로 중단되고(품질을 낮춘 결과로 대체하지 않음) 다음 날 0시(UTC, 한국시간 오전 9시)에 재개됩니다.
- 운영자가 점검·중단 중이면 연결이 계속 실패할 수 있습니다. 별도 상태 페이지는 없습니다.

오류 코드가 보일 때: `429` 속도 제한(잠시 후 재시도) · `503` 혼잡·점검·중단(즉시 재시도가 실패할 수 있음) · `413` 요청이 너무 큼.

## 이용상 주의 및 면책

본 서비스는 정책 문서의 근거 탐색을 돕기 위한 무료·무SLA 공개 알파 도구로, 현 상태 그대로 제공됩니다. 운영자는 검색 결과의 정확성·완전성·특정 목적 적합성과 계속 제공을 보증하지 않으며, 예고 없이 변경·중단·종료할 수 있습니다. 검색 결과는 공식 유권해석이나 행정·법적 판단의 최종 근거가 될 수 없으므로, 업무·의사결정에는 반드시 각 문서의 원문(답변 하단 URL)과 소관 기관의 공식 발표를 확인하십시오. 운영자의 고의 또는 중대한 과실 등 관계 법령상 배제할 수 없는 책임을 제외하고, 서비스 이용·중단으로 인한 손해에 대해 책임지지 않습니다.
